# Project Documentation

This directory stores design and experiment notes for the self-pruning network project.

## Contents

- architecture notes for the autodiff and pruning pipeline
- experimental setup and methodology
- result interpretation and tradeoff analysis
- any design artifacts that support the final write-up

## Expected focus

The project is built around:

1. custom NumPy autodiff engine
2. sparse training loop with masks
3. pruning scheduler and importance scoring
4. accuracy/sparsity tradeoff evaluation

This documentation should grow as the implementation becomes more concrete.
